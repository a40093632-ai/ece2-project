# 2차 통합 구현 인터페이스

현재 저장소에는 STM32와 시계·스톱워치·예약·계측 표시를 연결한 2차 통합 소스가 포함돼 있다.
Vivado system2 비트스트림 생성 및 50 MHz 타이밍 검사를 통과했다.
최신 검증 결과와 남은 실물 확인 항목은 루트 README.md를 참고한다.
아래 내용은 UART 규격과 버튼 동작을 설명한다. 실물 통합 시연 완료를 의미하지 않는다.

## 변경한 버튼 약속

계획서의 '모든 화면에서 CANCEL' 항목은 이번 사용자 결정으로 아래처럼 바뀌었다.
스톱워치의 '정지'는 2번 일시정지이고, 3번은 기록을 지우는 초기화다.

| 숫자 버튼 | 역할 |
|---|---|
| 1(K4) | 전체 리셋, 모든 기능 초기화와 Gate OFF. 2차 기본 화면은 시계 |
| 2(N8) | 스톱워치 화면에서는 시작/일시정지/재개, 예약 화면에서는 새 예약 시작 |
| 3(N4) | 스톱워치 화면에서는 스톱워치만 초기화, 예약 화면에서는 예약만 취소/오류 확인 |
| 4(N1) | 시계(0) → 스톱워치(1) → 예약(2) → 측정(3) → 시계 |
| 5(P6) | 시계 화면 날짜/시각 선택, 측정 화면 V/I/P/E 선택 |

시계·측정 화면에서 3번은 실행 중인 기능을 취소하지 않는다.
화면 전환만으로 스톱워치나 예약을 멈추지 않는다. 예약에는 일시정지가 없다.
MODE 또는 SET과 START/CLEAR가 동시에 들어오면 화면 동작을 우선하고 실행 동작은 만들지 않는다.
오류 확인은 정상 계측이 돌아온 뒤 예약 화면에서 3번, 그 뒤 별도 2번으로 새 실행한다.
1번 전체 리셋과 계측 오류에 따른 OFF는 화면과 무관하다.

## UART 물리 설정

9600 baud, 8 data bits, no parity, 1 stop bit, idle HIGH, LSB first.
기본 클록 50MHz, 비트당 5208클록. CLK_HZ는 1000의 배수이며 최소 1000, UART DIV는 최소 8이어야 한다.
TX/RX는 서로 교차 연결하고 GND를 공통으로 연결한다. STM32의 PC USART2와 FPGA USART3는 분리한다.

## 프레임

ASCII 고정 폭이다. `$` 시작, `*` 뒤 두 자리 대문자 16진 XOR 검사합, LF 종료다. 수신은 CRLF도 허용한다.
XOR 범위는 `$` 다음 T/M/F/S부터 `*` 직전까지이며 쉼표를 포함한다. `$`, `*`, 검사합 글자, CR/LF는 제외한다.
순번·실행 ID만 대문자 16진수 4자리, 나머지는 부호 없는 10진수다. 부호/공백/소수점/필드 생략은 허용하지 않는다.
수신 중 새 `$`가 오면 미완성 프레임을 버리고 다시 시작한다. 바이트 간격 100ms 초과도 미완성 프레임을 버린다.

### T: STM32 → FPGA, 1초 주기

```text
$T,ssss,YYYYMMDD,hhmmss,w,v*CC\n
```

| 필드 | 폭 | 의미 |
|---|---:|---|
| ssss | HEX 4 | T 전용 16비트 순번 |
| YYYYMMDD | DEC 8 | 날짜, 지원 범위 2000~2099 |
| hhmmss | DEC 6 | 24시간제 시각 |
| w | DEC 1 | 월요일1~일요일7 |
| v | DEC 1 | 1=시각 설정 완료, 0=미설정/무효 |

정상 날짜·시각·윤년·요일 일치를 검사한다. v=0이면 날짜/시각 0도 허용하고 시각을 무효로 처리한다.
새 T가 3초 동안 없으면 표시용 time_valid를 0으로 한다. 상대시간 예약의 계측 감시와는 독립이다.
RTC를 FPGA에서 다시 세지 않는다. STM32가 새 시각을 보내야 표시 데이터가 갱신된다.

### M: STM32 → FPGA, 200ms 주기

```text
$M,ssss,iiii,vvvvv,uuuuuu,pppppp,eeeeeeeeeeee,rrrrrrrrrrrr,v,a*CC\n
```

| 필드 | 폭 | 의미 |
|---|---:|---|
| ssss | HEX 4 | M 전용 16비트 순번 |
| iiii | HEX 4 | FPGA가 요청한 실행 ID. 실행 전에는 0000 사용 가능 |
| vvvvv | DEC 5 | INA219 버스전압 mV, 0~26000. 부하 양단 전압이 아님 |
| uuuuuu | DEC 6 | 부하 방향 전류 µA, 0~999999 |
| pppppp | DEC 6 | 부하 전력 µW, 0~999999 |
| eeeeeeeeeeee | DEC 12 | 전체 누적 에너지 µWh |
| rrrrrrrrrrrr | DEC 12 | 해당 실행의 에너지 µWh |
| v | DEC 1 | 1=새 계측 정상, 0=계측 무효 |
| a | DEC 1 | 1=해당 실행의 기준값 준비 완료, 0=미승인 |

계측 실패 시 v=0 프레임을 보낸다. 실패를 0A 정상 계측으로 바꿔 보내지 않는다.
전력은 MCU에서 I²×실측 Rload로 계산한다. 고정 저항 실험용이며 버스전압×전류로 대체하지 않는다.
에너지는 MCU가 단조 타이머의 실제 Δt로 누적한다. 내부 누적 정밀도를 유지하고 송신 시 µWh 정수로 변환한다.
0.694mWh=694µWh, 1300mWh=1300000µWh다. 표시 반올림과 별개다.
음의 전류·전력이나 표현 범위 초과는 MCU에서 오류 판정 후 v=0으로 보낸다. 값을 자릿수에 맞춰 잘라 정상값으로 보내지 않는다.
현재 규격은 약 1A·1W 미만의 이번 저항 부하 시험 범위다. 이를 넘는 부하에는 먼저 규격·범위 검토가 필요하다.

### F: STM32 → FPGA, 예약 종료 결과

`$F`는 `$M`과 같은 필드 폭을 쓴다. V/I/P에 마지막 유효 RUN 표본을 넣고, 이번 E에 확정된 에너지를 넣는다. `v`는 표본 유효 여부, 마지막 필드는 정상 완료(`1`)와 부분 결과(`0`)를 나타낸다. 현재 예약 ID의 터미널 상태에서 첫 유효 체크섬 프레임을 한 번 반영한다. 수신 대기 중에는 `RESULT PENDING`, 시간 초과 시 `RESULT MISSING`을 표시한다. `F` 프레임은 M 계측 감시 시간을 갱신하지 않는다.

### S: FPGA → STM32, 200ms 및 상태 변경 시

```text
$S,ssss,iiii,s,rrrrr,o,r*CC\n
```

| 필드 | 폭 | 의미 |
|---|---:|---|
| ssss | HEX 4 | S 전용 송신 순번 |
| iiii | HEX 4 | 실행 ID |
| s | DEC 1 | 예약 상태 |
| rrrrr | DEC 5 | WAIT/RUN 남은 초, 다른 상태는 0 |
| o | DEC 1 | FPGA Gate 출력 명령 0/1. 실제 전류 흐름의 보증이 아님 |
| r | DEC 1 | 종료/오류 이유 |

송신은 한 프레임의 일관된 스냅샷이다. 송신 중 바뀐 최신 상태는 다음 프레임에 반영한다.
한 프레임보다 짧은 중간 상태를 모두 로그로 저장하는 이벤트 큐는 아니다.
상태는 0 IDLE / 1 WAIT / 2 RUN / 3 DONE / 4 ARM / 5 FAULT다. 1차의 1·2·3 의미는 유지한다.
이유는 0 없음 / 1 정상 종료 / 2 취소 / 3 계측 무효 / 4 계측 수신 중단 / 5 기준값 승인 timeout / 6 설정 오류 / 7 실행 ID·승인 유실이다.

T 31바이트×1회/초 + M 66바이트×5회/초 = 361바이트/초(8N1에서 3610bit/s).
반대 방향 S는 28바이트×5회/초=1400bit/s이며 상태 변경 시 추가 전송한다. 각 방향 9600bit/s 안에 들어간다.
MCU는 T와 M의 바이트를 서로 섞지 말고 완전한 프레임 단위로 직렬화한다.

## 순번·유효 데이터

T/M/S의 순번은 각각 독립이며 0000~FFFF에서 순환한다.
FPGA 수신은 첫 프레임 또는 `(새 순번-이전 순번) mod 65536`이 1~32767인 프레임을 새 데이터로 본다.
중복·뒤로 온 프레임은 데이터와 계측 감시 타이머를 갱신하지 않는다. FFFF→0000은 정상이다.
온전하게 해석된 v=0 계측은 순번과 관계없이 실행 중 OFF를 우선한다.
MCU만 재부팅해 순번을 초기화했다면 FPGA도 1번으로 리셋하여 새 수신 세션을 시작한다.
깨진 프레임은 폐기하고 frame_errors를 증가시킨다. 1초 동안 새 정상 M이 없으면 실행을 중단한다.

## 새 실행과 에너지 기준값

1. IDLE/DONE에서 예약 START. 정상 계측이 없으면 FAULT·OFF. 실행 시간 0초 또는 99999초 초과도 거부한다.
2. FPGA가 실행 ID를 증가시키고 ARM(4)을 회신한다. Gate는 OFF다.
3. MCU가 새 ID의 ARM을 처음 받으면 에너지 기준값을 한 번만 준비한다. 같은 ID의 반복 S로 기준값을 재설정하지 않는다.
4. MCU는 같은 ID로 새 M의 a=0을 적어도 한 번 전송하고, 준비 완료 후 그보다 새 순번의 a=1을 전송한다.
5. FPGA는 같은 ID에서 a=0 → a=1 확인 후 5초 WAIT → 10초 RUN을 수행한다. 이전 실행의 a=1만으로 켜지지 않는다.
6. ARM 승인에 1초 이상 걸리면 FAULT·OFF. WAIT/RUN 중 다른 ID나 a=0의 새 M이 오면 실행을 중단한다.

ARM에서 이번 에너지를 초기화한다. WAIT 동안 이번 에너지는 0이고, RUN의 유효 표본으로 에너지를 적분한다.
정확한 Gate ON/OFF 에지와 센서 적분 구간의 일치는 실물 UART 지연·취득 주기와 함께 검증해야 한다.
소프트웨어만으로 에지 순간의 에너지가 정확히 분리된다고 보증하지 않는다.
DONE의 실행 사용량은 다음 새 실행까지 유지한다. 전체 누적은 새 실행마다 지우지 않는다.

## 표시·스톱워치 담당에게 전달할 입력

`reservation_control`이 제공하는 값이다. 표시 담당은 UART를 별도로 해석하지 않는다.

| 포트 | 폭·단위 | 사용 |
|---|---|---|
| page | 2비트, 0~3 | 선택 화면. 표시 담당이 별도 page 카운터를 중복 구현하지 않음 |
| date_selected | 1비트 | 시계 화면 날짜 선택 여부 |
| measure_item | 2비트 | 0 Vbus / 1 I / 2 Pload / 3 E |
| watch_start, watch_clear | 각 1클록 | 기존 stopwatch의 start_pause, clear에 연결 |
| date_ymd, time_hms | 각 32비트 이진 정수 | 예: 20261116, 123456. BCD나 ASCII가 아님 |
| weekday | 3비트 | 월1~일7 |
| time_valid, measure_valid | 각 1비트 | 0일 때 정상 수치와 구분해서 표시 |
| reservation_state | 3비트 | 0~5 상태 |
| reservation_reason | 4비트 | 이유 코드 |
| remaining_seconds | 32비트 초 | 예약 남은 시간 |
| bus_mv | 32비트 mV | 버스전압 |
| current_ua | 32비트 µA | mA 소수 셋째 자리 표시 시 원값 사용 |
| power_uw | 32비트 µW | mW 소수 셋째 자리 표시 시 원값 사용 |
| total_uwh, session_uwh | 각 64비트 µWh | mWh 소수 셋째 자리 표시 시 원값 사용 |

기존 stopwatch의 clk/rst/tick_10ms는 계속 공급한다. 화면을 바꿨다고 모듈을 리셋하거나 tick을 끊지 않는다.
FPGA E 화면은 이번 실행 `session_uwh`를 표시한다. PC는 이번 실행과 전체 누적을 함께 표시한다.
최종 글리프·DP 위치·무효·범위 초과 표현은 표시 담당이 구현하고 실물 확인한다.

## 외부 핀과 단독 확인용 top

`reservation_board_top`은 예약·UART만 확인하는 임시 보드 top이다. 7세그먼트 화면이나 스톱워치를 포함하지 않는다.
실제 통합에서는 기존 top에 reservation_control과 조원 표시·스톱워치를 연결한다.
단독 top은 리셋 후 시계 페이지(0)이며, 4번을 두 번 눌러 예약 페이지(2)를 선택한다.
MCU 계측과 ARM 승인이 없으면 켜지지 않는 것이 정상이다. 감시를 우회하는 테스트 스위치는 넣지 않았다.

LED1~3은 예약 상태의 이진수 하위~상위 비트, LED4~5는 page의 이진수 하위~상위 비트,
LED6은 time_valid, LED7은 measure_valid, LED8은 Gate ON 명령이다.

| 외부 역할(이번 배정안) | 보드 커넥터 | FPGA 패키지 핀 |
|---|---|---|
| Gate 명령 출력 | PORT A I/O00 | F8 |
| MCU TX → FPGA RX | PORT A I/O01 | E8 |
| FPGA TX → MCU RX | PORT A I/O02 | A7 |
| 공통 기준 | 별도 GND 헤더 | GND |

전압 실측 전 외부 회로 배선은 연결하지 않는다. 이 배정과 3.3V HIGH/LOW를 실물에서 확인한다.
책 회로도 기준 SW5 PORT A 접점 OFF가 PI3C3245 통과 조건이다. 보드의 숫자 5번(P6)과 다른 스위치다.
Gate 경로에는 온보드 100Ω이 있고, 외부 330Ω 직렬 저항과 Gate–Source 20kΩ 풀다운을 그대로 사용한다.
GPIO는 부하 전원이 아니다. 부하는 별도 5V로 공급한다.
CFGBVS/CONFIG_VOLTAGE는 근거 없이 추가하지 않았다. 기존 구성 전압 경고의 확인 과제는 그대로 남는다.


## 조원 코드 통합 완료본 추가 설명
통합 top은 fpga/system/src/top.v이다. display_ctrl은 EXTERNAL_SELECTION=1로 화면 선택을 받는다.
수신 전압은 mV 정수이며 화면에서 V 소수 셋째 자리로 표시한다. 전류는 0.01 mA, 전력은 0.1 mW, 에너지는 0.001 mWh 단위로 표시한다.
기본 화면은 날짜, SET으로 시각/요일로 바뀐다. 예약 화면은 맨 앞 상태 번호와 남은 초를 함께 표시하고 LED5~7도 유지한다.
MCU와 FPGA는 이 문서의 $T/$M/$S만 사용한다. 조원 원본의 @B/@b는 사용하지 않는다.
