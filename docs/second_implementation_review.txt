수정
1) project_frame_rx: 64비트 날짜 나눗셈/나머지 연쇄 제거. ASCII 날짜 성분을
직접 수집하고 윤년/월말/시각/요일을 여러 클럭으로 검증. 연도 2000~2099.
12자리 에너지의 최댓값 999999999999를 담을 수 있는 40비트 누산기 사용.
체크섬과 검증이 끝난 프레임만 한번에 반영한다.
2) display_ctrl/project_lcd_format: 남은 초의 BCD 변환을 32클럭으로 분리.
3) project_status_tx: 상태/ID/남은 초/Gate를 한번에 캡처하고, 32클럭 BCD 변환,
바이트별 프레임/체크섬 생성 후 전송. 기존 $S 규격과 200ms 주기는 유지.
4) display_value_adapter: I/10, P/100 이진 나눗셈을 제거하고 원래 값을 BCD로
변환한 뒤 소수 단위에 맞춰 자릿수를 선택한다. 단위·절삭 결과는 동일하다.
5) 예약 제어: 통신 타임아웃 후 MCU의 초기화된 T/M 순번을 재수신할 수 있게
복구. 센서 오류·타임아웃 FAULT는 자동으로 해제하지 않는다.
6) MCU RTC: 기존 실습의 다른 RTC 소스가 남아 있으면 백업 도메인을 초기화하고
LSE로 재설정. 분주/24시간/섀도 설정이 다르면 복구하고 PC 동기화를 요구한다.
TR 다음 DR을 읽어 날짜/시각을 같은 스냅샷으로 취득하고 요일도 검증한다.
7) LCD Hello 인사 대신 날짜/시각·스톱워치·예약·측정 표시, MCU Hello printf 제거.
8) TB는 순차 BCD 출력 지연을 기다리도록 보완. 통신 단절/MCU 재부팅 뒤
T/M 순번 재수신과 2026-11-16 23:59:59 -> 11-17 00:00:00 표시 수신을 검사.

사용 방법

verify_build.tcl -> 합성/배치배선/타이밍 검사, setup/hold 실패 시 bitstream 미생성.

회로/기능
Gate=PORT A I/O00 F8, MCU PC10 TX->I/O01 E8 RX, I/O02 A7 TX->MCU PC11 RX.
INA219 VCC=STM3V3, SCL=PB8(D15), SDA=PB9(D14), 공통 GND.
SW5 PORT A 접점 OFF=연결. 1 전체리셋, 2 시작/스톱워치 일시정지,
3 현재 화면만 초기화/예약취소/FAULT 확인, 4 화면전환, 5 시계/측정 SET.
예약은 상대시간 5초 대기/10초 실행, MCU 준비 확인 전 Gate OFF.
정해진 현재 시각에 ON하는 절대시각 예약과 설정 영구저장은 후속 목표다.
부하 50옴이면 RLOAD,50. 기본330옴은 리셋마다 적용되므로 다른 부하는 재설정.
PC 시간 동기화 전 WAIT PC TIME, 측정 수신 전 NO MCU DATA.
최종 보드 검증 전 부하 외부5V OFF, 비트스트림 새 빌드/다운로드 및 리셋 후
Gate-Source 약0V 확인. 센서 값/실제 저항/단자 방향/저항 정격도 별도 확인한다.
GPIO3.3V 측정만으로 CFGBVS/VCCO_0 설정을 확정하지 않는다.
